# Security Policy

## Supported Versions

This project is an academic engineering project and does not currently maintain multiple production versions.

| Version | Supported |
|---------|-----------|
| Latest | Yes |
| Older versions | No |

## Reporting a Security Issue

If you identify a security-related issue in this repository, please report it privately to the project maintainer rather than publicly exposing sensitive information.

When reporting an issue, please include:

- A description of the issue
- Steps to reproduce it
- Affected files or components
- Potential impact
- Any suggested solution, if available

## Scope

This policy primarily applies to the software, scripts, configuration files, and other digital components contained in this repository.

Physical hardware safety issues should be handled carefully and should not be treated as software security vulnerabilities.

## Response

Reports will be reviewed by the project maintainers and addressed when reasonably possible.
