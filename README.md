\# 5 V to 7 V High-Frequency Boost Converter



Python-based time-domain simulation and parametric analysis of a 5 V to 7 V boost converter.



\## Baseline Parameters



\- Input voltage: 5 V

\- Target output voltage: 7 V

\- Switching frequency: 100 kHz

\- Duty cycle: 35%

\- Inductor: 100 uH

\- Capacitor: 220 uF

\- Simulation load: 24 ohm

\- Hardware load: 27 ohm

\- Diode forward-drop approximation: 0.7 V



\## Simulation Studies



\- Duty-cycle analysis

\- Inductance analysis

\- Capacitance analysis

\- Load-resistance analysis

\- Switching-frequency analysis



\## Baseline Simulation Result



The Python time-domain simulation produced an average output voltage of approximately 6.992 V for a 5 V input and 35% duty cycle.
